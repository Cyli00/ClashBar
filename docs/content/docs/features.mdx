title: 功能总览
description: Rust + Tauri 客户端的面板、配置、监控与 Windows 集成。
---

ClashBar 将日常控制集中在 360 逻辑像素的托盘面板中。当前发布目标为 Windows 10/11 x64，macOS/Linux 安装包与系统集成未验证。

| 分类 | 功能 | 说明 |
| --- | --- | --- |
| 面板 | 固定、自动收起、独立侧边菜单、浅色/深色、中英语言 | [日常使用](/docs/daily-use) |
| 内核 | 选择、验证、启动、停止、重启、更新 | [快速开始](/docs/quick-start) |
| 配置 | 本地导入、多配置、删除归档、外部文件变更监测 | [配置与订阅](/docs/configuration) |
| 订阅 | 文件名、来源复制、单项/批量刷新、周期更新 | [配置与订阅](/docs/configuration) |
| 节点 | 代理组、模式、延迟排序、历史、隐藏组、组图标 | [日常使用](/docs/daily-use) |
| Provider | 代理/规则资源刷新、节点数、订阅用量与到期日、后台刷新进度 | [日常使用](/docs/daily-use) |
| 监控 | 实时速率、内存、连接、流量曲线、托盘网速 | WebSocket 与 HTTP 兼容回退 |
| 规则 | 搜索、类型/策略筛选、策略分组、规则提供者数量与更新时间 | [日常使用](/docs/daily-use) |
| 连接 | 搜索、TCP/UDP筛选、排序、单条/全部关闭、复制 | [日常使用](/docs/daily-use) |
| 日志 | 来源/级别过滤、搜索、复制、清空、磁盘轮换 | [日常使用](/docs/daily-use) |
| 接管 | 系统代理、绕过列表、TUN与协议栈 | [系统代理与 TUN](/docs/network-mode) |
| Wi-Fi | 当前SSID、权限状态、绑定、自动配置切换 | [SSID 策略](/docs/ssid-strategy) |
| 远程 | 增删改、探测、本机/远程切换、远程控制与日志 | [远程机器](/docs/remote-machine) |
| 设置 | 登录启动、内核自启、LAN/IPv6/TCP、5类端口、缓存与Geo | [设置与维护](/docs/settings) |
| 恢复 | 原代理快照、进程退出恢复、断网暂停与原配置恢复 | [常见问题](/docs/troubleshooting) |
| 命令 | 本地、LAN和远程端点的PowerShell代理环境变量 | [日常使用](/docs/daily-use) |

客户端更新会检查本仓库发布版本并打开发布页；不自动下载安装程序。TUN权限通过Windows UAC助手处理，无macOS setuid或XPC helper。

功能测试不能代替硬件验收。真实UAC、Wi-Fi切换、WinINet系统代理回合和多显示器混合DPI应按仓库 `desktop/VALIDATION.md` 验收；不会把模拟IPC的浏览器测试当作这些检查通过。
