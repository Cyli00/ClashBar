「设置」集中管理应用偏好与当前内核。Ctrl+, 或 Ctrl+Alt+5打开设置。

| 选项 | 行为 |
| --- | --- |
| 开机自启 | 当前用户登录Windows后启动ClashBar |
| 内核自启 | 应用初始化后启动已配置的本机内核，与登录启动独立 |
| 状态栏样式 | 图标和网速、仅图标、仅网速 |
| 语言 | 简体中文 / English |
| 外观 | 跟随系统、浅色、深色 |
| LAN / IPv6 / TCP并发 | 写入当前内核；本机偏好保存后在重启时保留 |
| 日志级别 | silent/error/warning/info/debug |
| 代理绕过 | 新增、移除、恢复默认、保存当前用户WinINet例外 |

## 端口

支持HTTP、SOCKS、混合、重定向、TProxy端口。0表示关闭对应监听；其它范围和冲突由客户端及内核校验。本机控制器固定在loopback，不能与代理监听冲突。

编辑后自动保存，也可按Enter重试。运行中修改需要验证和重新应用；失败时保留可操作错误。透明重定向和TProxy是否可用取决于内核与运行平台。

## 维护

内核运行时可以清理DNS/FakeIP缓存、更新Geo数据库和升级内核。升级结果区分成功、已经最新、失败，不将失败显示为成功。

客户端版本检查指向 [Cyli00/ClashBar Releases](https://github.com/Cyli00/ClashBar/releases)。发现新稳定版本后打开发布页，由用户选择安装包；没有后台自动安装器。

「打开配置目录」定位源配置库；「打开内核目录」定位所选可执行文件所在目录。两者不应被混同为同一个固定路径。
