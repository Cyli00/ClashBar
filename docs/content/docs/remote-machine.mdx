---
title: 远程机器
description: 保存、探测并控制HTTP(S) Mihomo External Controller。
---

顶部控制器入口可切换本机与远程机器。远程目标可以是路由器、服务器或另一台已启动mihomo的电脑。

## 添加与编辑

填写名称、主机、端口、HTTP/HTTPS与可选密钥。主机字段接受主机名、IPv4和IPv6，不包含协议、路径或端口。切换前会探测控制器版本。

密钥保存在Rust应用数据目录。编辑时不回传已存密钥；保留空编辑状态表示不替换，显式清除才删除保存的密钥。

## 操作范围

节点、模式、规则、连接、日志、TUN、端口与维护请求作用于当前远程控制器。远端权限和支持的API取决于其内核。

切换远程不停止本机后台内核。本机配置导入、删除与进程启停在远程目标下受限；登录自启等应用设置仍是这台Windows机器的设置。

系统代理开关修改本机WinINet设置，可以指向远程代理端口。远端必须允许局域网访问；控制器端口不是代理端口。

## 连接与鉴权

HTTP(S)与WebSocket请求使用所选目标的Bearer密钥；不将密钥塞入监控URL。HTTPS使用系统可信证书验证。网络或鉴权失败会保留失败状态供修正后重试。

仅管理你有权控制的实例，并限制远端External Controller的访问来源。问题反馈请隐藏地址中的私人信息和密钥。
