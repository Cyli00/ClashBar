配置菜单位于「节点」页。应用保留源 YAML，并为内核生成独立运行配置。导入不会修改你原来的文件。

## 数据目录

ClashBar使用Tauri当前用户应用数据目录，应用标识为 `io.github.cyli00.clashbar`。Windows通常位于 `%APPDATA%\io.github.cyli00.clashbar`；应用的「打开配置目录」入口以实际运行路径为准。

| 路径 | 用途 |
| --- | --- |
| `settings.json` | 偏好、配置指针、订阅元数据、远程目标 |
| `profiles/` | 导入的源 YAML |
| `runtime/` | 运行配置、内核资源、Provider隔离缓存 |
| `deleted-profiles/` | 从配置列表删除后的归档 |
| `logs/` | 持久日志与轮换备份 |
| `icons/` | 代理组图标缓存 |

所选 `mihomo.exe` 保留在你指定的位置，可通过「打开内核目录」定位。配置、订阅链接和远程密钥可能包含私人信息，备份请保存在可信位置，提交Issue前脱敏。

## 本地配置与切换

导入 `.yaml` 或 `.yml` 后可在配置菜单选择。运行中切换先验证候选，启动成功后提交活动配置；失败时尝试恢复原内核和代理状态。

文件型Provider可随本地YAML导入；引用资源必须位于导入配置目录内，应用会复制至隔离缓存。复杂代理组、规则和DNS仍在YAML维护。

配置目录外部新增、删除和内容修改会自动核对；当前配置内容变更也走验证和恢复流程。不要手动改写包含临时鉴权信息的运行副本。

## 订阅

导入时填写HTTP/HTTPS地址和可选文件名。默认开启每6小时更新，最小间隔1小时，可关闭自动更新。

每份订阅支持立即刷新、编辑来源和周期、复制来源链接；配置菜单还提供批量更新。单个来源失败不会阻止后续项，失败后按周期等待下一次检查。活动配置内容更新后会自动应用；内容未变化不会无故重启。

下载限制为8MiB、30秒和最多10次重定向。支持私有网络订阅；地址不能包含用户名/密码或URL片段。订阅服务收到与所选mihomo版本匹配的User-Agent。

## 删除与恢复

删除同时移除订阅和SSID关联。配置文件移入 `deleted-profiles/`，不会永久擦除。删除当前配置时先验证和切换后继配置；删除最后一份配置会停止内核。

恢复时将归档YAML重新导入。自动更新地址和Wi-Fi绑定需重新设置。
