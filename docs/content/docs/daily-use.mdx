点击Windows系统托盘中的ClashBar图标打开面板。顶部依次提供控制目标、固定、重启、启停和退出；下方是规则 / 全局 / 直连与五个标签。

## 节点

代理组支持选择节点、单组和全部延迟测试、延迟排序、历史和隐藏组。Provider显示节点数量、更新信息以及内核返回的订阅用量和到期日。启动、重启、切换配置后会后台刷新Provider，单项失败后继续其它资源。

实时流量、内存和连接来自所选内核。后台监控继续为托盘网速提供数据；不使用示例值填补缺失指标。

## 分流与连接

「分流」可以按目标、类型和策略搜索，筛选或按策略分组。规则提供者统计的是条目数量，不是命中次数。

「连接」支持域名/IP搜索、TCP/UDP筛选、时间或流量排序、单条和全部关闭。右键菜单可以复制Host和连接ID。

## 日志

日志可按来源与级别筛选，搜索、复制单条或全部、清空。后端保存带时间戳的ClashBar应用动作日志，每10MiB轮换一次，最多保留5份备份；界面只保留有界的近期记录。包含URL或凭据信息的内容会被隐藏。

## 终端代理命令

「复制终端命令」生成PowerShell环境变量命令。loopback入口用于本机，LAN入口使用检测到的网卡IPv4；远程模式使用当前远程端点。LAN访问还需要允许局域网、可达端口及防火墙放行。

命令仅影响粘贴执行的终端会话。它不会修改全系统环境变量。

## 键盘快捷键

快捷键在面板拥有焦点时生效，文本输入和输入法组合期间保留编辑操作。

| 操作 | Windows快捷键 |
| --- | --- |
| 系统代理 | Ctrl+S |
| TUN | Ctrl+E |
| 规则 / 全局 / 直连 | Ctrl+Shift+1 / 2 / 3 |
| 节点 / 分流 / 连接 / 日志 / 设置 | Ctrl+Alt+1 / 2 / 3 / 4 / 5 |
| 设置 | Ctrl+, |
| 启动 / 重启内核 | Ctrl+Shift+R |
| 停止内核 | Ctrl+Shift+. |
| 复制当前端点命令 | Ctrl+Alt+C |
| 收起侧边菜单或面板 | Esc |

远程目标下本机启停快捷键不可用。标准Ctrl+C仍用于复制已选择的文本。
