配置有效且节点可用后，再开启系统代理或TUN。两种方式可以分别控制。

## 系统代理

ClashBar设置当前Windows用户的WinINet/LAN代理，使用当前目标的HTTP/SOCKS/混合端口。它不修改机器级WinHTTP，也不能强制所有软件遵守系统代理。

修改前保存原设置。停用、退出或恢复时先检查所有权；其它软件已改写代理则不会用旧快照覆盖它。强制终止后，可重新打开ClashBar恢复保存的快照。

绕过列表使用Windows WinINet语法，支持主机/域名通配等条目。默认包含本地名称和loopback。不要把macOS的所有例外语法视为Windows等价行为。

选择远程控制目标时，系统代理仍修改这台Windows机器，并指向远端实际代理端口。远端须允许本机访问。

## TUN

本机TUN需要管理员权限。应用通过Windows UAC启动专用助手，由助手管理所选mihomo进程和父进程退出；不会安装macOS helper或设置setuid。

1. 选择可信内核和有效配置并启动。
2. 开启TUN并在Windows UAC提示中授权。
3. 应用检查内核返回的TUN状态，失败时保留错误供重试。

可选 `system`、`gvisor`、`mixed` 和 `mips`；`mips` 要求mihomo 1.19.31或更新版本。远程TUN通过远端控制器设置，远端权限由其管理者准备。

实际TUN转发还取决于内核、系统驱动和权限。编译通过或控制器模拟测试不代表真实UAC和流量验收已经完成。

## 断网与恢复

后台从Windows网卡状态判断网络连接，不主动请求公网探测地址。断网时暂停原本运行的本机内核；恢复后尝试重启同一配置和原系统代理。用户主动停止、改选配置或切换目标会取消旧的自动恢复意图。
