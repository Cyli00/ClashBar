title: 关于 ClashBar
description: Rust + Tauri迁移、平台范围与开源许可。
---

本仓库基于 [Sitoi/ClashBar](https://github.com/Sitoi/ClashBar) 的产品与界面，将客户端迁移为Rust + Tauri 2，仅维护 `desktop/`。代理内核继续使用 [MetaCubeX/mihomo](https://github.com/MetaCubeX/mihomo)。

保留紧凑面板、五标签、侧边菜单和常用控制路径，迁移配置、订阅、远程控制、监控、系统代理、TUN和Wi-Fi策略。Windows权限与系统集成使用对应平台实现。

发布目标为Windows 10/11 x64；macOS/Linux安装包未验证。旧macOS的3MB/14MB统计不能作为新客户端的体积声明。
