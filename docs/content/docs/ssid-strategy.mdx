---
title: SSID 策略
description: 使用Windows当前Wi-Fi名称绑定并切换本机配置。
---

配置菜单中的Wi-Fi自动切换用于让家庭、办公等网络使用不同本机配置。

1. 连接目标Wi-Fi，打开配置菜单并启用自动切换。
2. 读取当前SSID；权限不足时使用「打开Wi-Fi权限设置」并在Windows定位设置中允许访问，再刷新。
3. 将当前Wi-Fi绑定到一份配置。
4. 后续网络匹配时，应用通过正常配置验证和切换流程应用该配置。

关闭自动切换保留已有绑定。可以解除当前网络或指定SSID的绑定；删除配置时同步清理其绑定。

客户端只查询当前已连接接口，不扫描附近Wi-Fi，不读取无线密码。状态区分未请求、已连接、未连接、权限不足、WLAN服务不可用、无无线网卡及其它系统错误。

远程控制目标下不自动改选本机配置。无法读取SSID、配置不存在或验证失败时不会假装切换成功。真实无线网络切换与权限提示仍需在有Wi-Fi硬件的Windows环境验收。
