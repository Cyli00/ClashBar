---
title: 快速开始
description: 在 Windows 安装 ClashBar、选择内核、导入配置并连接。
---

本仓库维护 Rust + Tauri 2 客户端，当前安装目标是 Windows 10/11 x64。旧 macOS 的 DMG、Homebrew 和 helper 安装步骤不适用于此版本。

## 1. 安装 ClashBar

从 [本仓库 Releases](https://github.com/Cyli00/ClashBar/releases) 或 GitHub Actions 的 Windows Desktop 产物中获取 Windows NSIS 安装器。安装前核对来源；当前构建未代码签名。应用使用 WebView2 Runtime。

启动后点击系统托盘中的 ClashBar 图标。主面板宽 360 逻辑像素，不显示常驻任务栏窗口。再次点击图标或按 Esc 收起；顶部固定按钮让面板在点击外部后仍保持显示。

## 2. 准备 Mihomo 内核

含内核安装包会自动准备 mihomo，并保留已有的内核选择。使用无内核安装包时，从 [MetaCubeX/mihomo Releases](https://github.com/MetaCubeX/mihomo/releases) 获取 Windows x64 内核，解压到固定目录，然后在 ClashBar「设置」中选择 `mihomo.exe`。

应用会执行你选中的程序进行配置验证和启动。更换内核前先停止本机内核，再选择新文件。

## 3. 导入配置

在「节点」页打开配置菜单，选择本地 YAML 或导入 HTTP(S) 订阅。默认配置用于初始设置，不包含你的订阅节点。

订阅可以指定名称、开启自动更新并设置小时数。默认 6 小时、最小 1 小时。配置保存、刷新和删除行为见 [配置与订阅](/docs/configuration)。

## 4. 启动并验证

1. 选择配置并点击启动；应用先执行 `mihomo -t`。
2. 控制器就绪后选择规则 / 全局 / 直连。
3. 在代理组中选择节点，执行延迟测试。
4. 开启系统代理；需要透明代理时再开启 TUN。
5. 用「连接」「日志」确认请求和错误。

本机 TUN 需要 Windows UAC 授权；系统代理修改当前用户 WinINet 设置。两种接管方式的边界见 [系统代理与 TUN](/docs/network-mode)。

## 切换内核

停止内核后在设置中选择新文件。源配置和保存的偏好继续保留；新内核仍须通过配置验证及控制器就绪检查。切换后遇到缓存或 Geo 资源错误，可打开内核/配置目录并结合日志定位，避免删除整个数据目录。

## 退出与卸载

退出 ClashBar 会恢复仍由它管理的系统代理设置，并停止自己的内核进程。卸载前先正常退出，再通过 Windows「已安装的应用」卸载。配置和订阅可能包含凭据，备份与清理请按 [配置与订阅](/docs/configuration) 中的数据目录说明进行。
